# KaloriApp

Günlük kalori takibi için Kotlin ile yazılmış bir Android uygulaması.

## Özellikler

- E-posta ile kayıt ve giriş
- Ana sayfada günlük kalori takibi
- Besin bilgilerini FatSecret API üzerinden arama
- Haftalık özet ekranı
- Kişisel hedef (kalori ihtiyacı) hesaplayıcı
- Profil ekranı

## Kullanılan teknolojiler

- Kotlin, Android SDK (XML arayüzler)
- Firebase Authentication ve Realtime Database
- Retrofit ve Gson (FatSecret API istekleri)
- Kotlin Coroutines

## Çalıştırma

1. Projeyi Android Studio ile aç.
2. Firebase konsolundan kendi `google-services.json` dosyanı indirip `app/` klasörüne ekle. Bu dosya depoda yer almaz.
3. Bir emülatör ya da cihaz seçip çalıştır.
